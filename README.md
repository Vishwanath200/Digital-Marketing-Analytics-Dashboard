# Digital Marketing Campaign Analysis

## Project Overview

This project demonstrates practical digital marketing analysis using Excel and Power BI. It covers SEO, keyword research, campaign performance analysis, competitor benchmarking, and interactive dashboards.

## Objectives

- Analyze marketing campaign performance
- Perform keyword research
- Conduct competitor analysis
- Build an interactive Power BI dashboard
- Generate business insights and recommendations

## Tools Used

- Microsoft Excel
- Power BI
- GitHub
- Canva (for presentation)

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Keyword Research
4. Campaign Analysis
5. Competitor Analysis
6. Dashboard Creation
